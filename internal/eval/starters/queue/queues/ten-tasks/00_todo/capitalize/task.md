# Capitalize

Add a `capitalize` subcommand to `tools.sh`.

Print the input with its first character upper-cased and the rest unchanged.

## Acceptance criteria
- `sh ./tools.sh capitalize "abc"` prints `Abc`
- `test.sh` gains a case for `capitalize` and still passes
- every subcommand that already worked still works
